# Система регистрации участников вебинаров

## Назначение

Приложение предназначено для организации регистрации слушателей на
образовательные онлайн-вебинары. Пользователь выбирает интересующее
мероприятие из расписания, указывает своё имя и email, после чего получает
подтверждение регистрации. Система решает задачу учёта заявок и контроля
посещения вебинаров.

## Целевая аудитория

- слушатели вебинаров, которые записываются на мероприятия;
- организаторы вебинаров, которым нужно вести список зарегистрированных
  участников и отмечать факт посещения.

## Предметная область

Организация и проведение образовательных онлайн-мероприятий. В рамках
предметной области рассматриваются расписание вебинаров, заявки на участие,
данные участников и отметки о посещении.

## Основные сущности

- пользователь (участник вебинара);
- вебинар (мероприятие с названием, спикером, датой и временем);
- регистрация (связь пользователя и вебинара);
- посещение (факт участия зарегистрированного пользователя в вебинаре).

## Основные функции

- просмотр расписания доступных вебинаров;
- выбор вебинара и регистрация по имени и email;
- проверка корректности введённых данных;
- вывод подтверждения регистрации с датой и временем мероприятия;
- в дальнейшем — ведение списка зарегистрированных участников и отметка
  посещения.
